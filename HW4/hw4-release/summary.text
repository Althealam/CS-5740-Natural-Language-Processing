\subsubsection{Jailbreak Dataset Creation}
I implemented a comprehensive rule-based adversarial data generation system with \textbf{6 distinct attack strategies}:

\begin{enumerate}[leftmargin=*]
    \item \textbf{Spelling Attacks}: Character substitution using leetspeak and Cyrillic characters
    \begin{itemize}
        \item Example: \texttt{ex3rcise},
        \texttt{m0rning}, \texttt{w0rk out}
        \item Substitutions: a$\rightarrow$@/4/a, e$\rightarrow$3/e, i$\rightarrow$1/!/i,
        o$\rightarrow$0/o, s$\rightarrow$\$/5, g$\rightarrow$9
    \end{itemize}
    
    \item \textbf{Multilingual Mixing}: Code-switching across 5 languages
    \begin{itemize}
        \item Languages: Chinese, Hindi, German, Spanish, French
        \item Example: \texttt{Let's exercise in the morning} mixed with non-English words
    \end{itemize}

    \item \textbf{Negation Confusion}: Double negatives and complex negation patterns
    \begin{itemize}
        \item Example: \texttt{"I don't want to avoid exercise"} (unsafe)
        \item Example: \texttt{"I hate early workouts and avoid it"} (safe)
        \item This strategy was particularly effective at fooling baseline models
    \end{itemize}

    \item \textbf{Implicit Semantics}: Euphemistic and metaphorical language
    \begin{itemize}
        \item Example: \texttt{"Get our blood pumping"}, \texttt{"Meet when the sun rises"}
        \item Avoids direct mentions of exercise or morning activities
    \end{itemize}

    \item \textbf{Distracted Text}: Context injection with irrelevant prefixes/suffixes
    \begin{itemize}
        \item Prefixes: \texttt{"Hi Bob, hope you're well."}, \texttt{"BTW, random thought:"}
        \item Suffixes: \texttt{"Let me know what you think!"}, \texttt{"Thanks for considering this."}
    \end{itemize}

    \item \textbf{Abbreviations and Slang}: Informal language and text-speak
    \begin{itemize}
        \item Example: \texttt{"yoga tmrw?"}, \texttt{"Quick run b4 work?"}
        \item Common abbreviations: tmrw, morn, b4, @
    \end{itemize}
\end{enumerate}

The jailbreak generation script (\texttt{generate\_jailbreaks.py}) produces a balanced dataset with 50 samples per class (100 total), evenly distributed across all 6 strategies.

\section{Key Findings}

\begin{enumerate}
    \item \textbf{Adversarial robustness matters}: The jailbreak dataset significantly improved model robustness against adversarial attacks, particularly negation confusion.

    \item \textbf{Negation is challenging}: Double negatives proved to be the most effective attack strategy, highlighting the complexity of semantic understanding.

    \item \textbf{Fast convergence}: The model achieved >96\% validation accuracy after just 1 epoch, reaching peak performance at epoch 3.

    \item \textbf{Data quality over quantity}: Strategic adversarial examples (100 samples) provided substantial improvement despite small size relative to full dataset.

    \item \textbf{Multilingual mixing}: Code-switching attacks require careful handling but the fine-tuned model handles them well.
\end{enumerate}

\section{Limitations and Future Work}

\subsection{Current Limitations}
\begin{itemize}
    \item Some false positives on benign queries (e.g., "How do I make a birthday cake?")
    \item Model may be overfitting to training distribution
    \item Limited evaluation on completely out-of-distribution examples
    \item Jailbreak strategies are rule-based and may not cover all adversarial patterns
\end{itemize}

\subsection{Potential Improvements}
\begin{enumerate}
    \item Expand jailbreak dataset with more diverse attack strategies
    \item Implement ensemble methods or uncertainty quantification
    \item Add regularization techniques to reduce overfitting
    \item Conduct error analysis on validation set misclassifications
    \item Explore larger models (e.g., BERT-base, RoBERTa) for comparison
    \item Implement adversarial training techniques
\end{enumerate}
